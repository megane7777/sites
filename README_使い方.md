# My Links

URLを保存・整理するためのシンプルなリンク管理サイトです。

## ファイル
- `index.html`：ページの構造
- `style.css`：デザイン
- `script.js`：リンク管理などの機能

## 起動方法
1. ZIPを展開します。
2. `my_links` フォルダーをVS Codeで開きます。
3. `index.html` をブラウザで開きます。VS CodeのLive Server拡張機能を使ってもOKです。

## 主な機能
- リンクの追加・編集・削除
- URL、タイトル、説明文、メモ、画像URL、複数カテゴリー
- お気に入り、検索、カテゴリー絞り込み
- カードのドラッグ並べ替え
- 文字・カードサイズ・背景色・カード色の変更
- JSONバックアップのダウンロードと復元（統合／全入れ替え）
- 設定画面内の使い方説明

## 大切な注意
- データはブラウザの `localStorage` に保存されます。ブラウザのデータ削除、別ブラウザ・別端末ではデータが共有されません。
- JSONバックアップを定期的にダウンロードし、安全な場所に保管してください。
- URLからタイトル・画像を取得する機能は、接続先サイトの設定（CORSなど）により失敗する場合があります。その場合はタイトルや画像URLを手入力してください。
- この版ではログイン機能やクラウド同期はありません。
- 公開サイトはURLを知っている人がアクセスできます。登録したリンク情報はサイトを閲覧できる人に見える可能性があります。個人情報や秘密のURLは登録しないでください。

## GitHub Pagesで公開する場合
この3ファイルをGitHubリポジトリのトップ階層にアップロードし、リポジトリの Settings → Pages から公開設定を行います。公開後もデータは閲覧者それぞれのブラウザ内に保存されます。
